# 0009. Palindrome Number (Easy)

## 문제 요약
정수 `x`가 앞에서 읽어도, 뒤에서 읽어도 같은 수(회문)이면 `true`, 아니면 `false`를 반환한다.

## 풀이 1: 문자열 변환 후 양 끝 비교
- `x`를 문자열로 바꾼 뒤 한 글자씩 배열로 나눈다.
- `i`번째 글자와 뒤에서 `i`번째 글자(`arr.length-1-i`)를 비교한다.
- 시간 복잡도 O(n), 공간 복잡도 O(n) (n = 자릿수)
- 결과: Accepted, 37ms (Beats 6.16%)

## 풀이 2: 숫자 뒤집기
- 문자열로 바꾸지 않고, `% 10`과 `/ 10`으로 숫자를 **끝자리부터 하나씩 떼어** 거꾸로 붙인다.
- 원래 값은 `original`에 따로 저장해 두고, 다 뒤집은 수와 비교한다.
- 음수는 `-` 때문에 회문이 될 수 없으므로 바로 `false`.
- 시간 복잡도 O(log n), 공간 복잡도 O(1) (자릿수만큼 반복)

```java
class Solution {
    public boolean isPalindrome(int x) {
        if(x < 0) {
            return false;
        }

        int original = x;
        int reversed = 0;

        while( x > 0) {
            int digit = x % 10;               // 끝자리를 꺼낸다
            reversed = reversed * 10 + digit; // 뒤집은 수 뒤에 붙인다
            x /= 10;                          // 끝자리를 없앤다
        }

        return original == reversed;
    }
}
```

## 배운 점
- **`% 10`과 `/ 10`으로 숫자를 한 자리씩 다룰 수 있다.**
  `x % 10`은 끝자리를 꺼내고, `x / 10`은 끝자리를 없앤다.
  문자열 변환 없이 숫자만으로 자릿수 연산이 가능하다.
- **`reversed * 10 + digit`은 숫자를 뒤에 이어 붙이는 공식이다.**
  `121`이면 `reversed`가 `1 → 12 → 121`로 바뀐다.
- **반복하면서 `x`가 바뀌므로 원래 값을 따로 저장해야 한다.**
  반복문이 끝나면 `x`는 0이 되기 때문에 `original`에 미리 담아 두고 비교한다.
- **문자열 변환을 없애면 메모리를 아낄 수 있다.**
  풀이 1은 자릿수만큼 문자열 배열을 만들지만(O(n)), 풀이 2는 변수 몇 개만 쓴다(O(1)).
- **음수 같은 예외 케이스를 먼저 걸러내면 로직이 단순해진다.**
- 참고: 풀이 1에서 `i`를 끝까지 돌리면 같은 쌍을 두 번 비교한다.
  `i < arr.length / 2`까지만 돌려도 충분하다.

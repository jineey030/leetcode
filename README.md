├── 🟢 Easy/

1. ⏱️ **혼자 풀기**: 20~30분 동안 스스로 고민합니다.
2. ✅ **제출 & 분석**: Runtime 분포 그래프에서 내 풀이의 위치를 확인합니다.
3. 📖 **다른 풀이 공부**: Editorial과 Solutions(Most Votes)에서 더 나은 접근법을 찾습니다.
4. ✍️ **기록**: 풀이를 개선하고, 배운 점을 README에 정리합니다.
